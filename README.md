# AES-RSA 하이브리드 암호 시스템
RSA와 AES를 결합한 하이브리드 암호화 구조를 C++로 직접 구현한 프로젝트입니다.
외부 암호 라이브러리 없이 RSA, AES-256 알고리즘의 핵심 로직을 로우레벨에서 구현했습니다.

## 프로젝트 개요
- 개발 언어: C++ (Visual Studio 2022)
- 연구 기간: 2026.03 ~ 2026.06 (15주, 1인 프로젝트)
- 목적: 학부 보안 전공 학습 프로젝트 — 암호 알고리즘의 내부 동작 원리 이해 및 하이브리드 구조 구현

## 주요 기능
- RSA 키 생성 (소수 검증, 확장 유클리드 알고리즘 기반 개인키 산출)
- AES-256 암복호화 (S-Box, GF(2^8) 갈루아 곱셈, 14라운드 구현)
- RSA로 AES 세션키를 보호하는 하이브리드 암복호화 흐름
- 데이터 크기별 성능 벤치마크 (100회 반복 측정, CSV 자동 저장)
- Python 기반 성능 시각화
